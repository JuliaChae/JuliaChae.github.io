<strong>Unsupervised Multimodal Representation Learning for Robot Controls</strong>
      <br> [Research Project] @ <strong><a href="https://rvl.cs.toronto.edu/">RVL</a></strong>. With Yewon L., Pranit C.
      <br> <br> Investigated how unsupervised representation learning could be utilized in an imitation learning (IL) task such as robot path following. In this project, we successfully trained a multimodal representation from unlabelled path traversal data, fine-tuned on minimal labeled data.
