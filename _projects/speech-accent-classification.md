<strong>Accent Classification Network</strong>
      <br>[Final Project], University of Toronto, APS360 Applied Fundamentals of Machine Learning. With Mingshi C., Catherine G., Rocco R.
      <br> <a href="/assets/pdf/APS360_FinalReport.pdf">Detailed Report</a> / Code Coming Soon
      <br> <br> Motivated by challenges experienced with voice-controlled devices, our team developed a neural network speech accent classifier which takes an accented English phrase as input and correctly identifies the origin of that speaker’s accent. The network developed was a CRNN architecture with mixed convolutional and recurrent neural network layers which learned both temporal and characteristic features of the audio data. The audio was processed into Mel-frequency cepstral coefficients (MFCC) features for input.
